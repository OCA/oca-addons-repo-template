# Contribution guideline

## Develop and test

To develop the template you need `copier` which you can install by following its
[documentation](https://copier.readthedocs.io/en/stable/#installation).

Test dependencies are listed in `pyproject.toml` using the `dev`
[dependency group](https://packaging.python.org/en/latest/specifications/dependency-groups/).

To run tests, the easiest is `uv run pytest`. This will automatically install the `dev`
group in a local `.venv` virtual environment and run the tests.

## GitHub Actions security

The workflows generated by this template, as well as the workflows of this repository
itself, pin every action to a full commit SHA, with the human-readable version in a
trailing comment. Tags are mutable, so a compromised upstream repository could point an
existing tag at malicious code, which would then run with access to the workflow
secrets. Please keep that convention when adding or updating an action.

Dependabot bumps the pins of this repository's own workflows, but it cannot parse the
Jinja templates in `src/.github/workflows/`, so those pins have to be bumped manually.

The `ghcr.io/oca/oca-ci` container images are intentionally referenced by the `latest`
tag instead of a digest, because the tests are meant to run against the current OCA CI
image and a digest pinned here would only be refreshed when a repository re-runs Copier.
